# EGFR Drug Discovery Analytics

## Project Overview
An exploratory computational analysis of EGFR inhibitors using Python, RDKit and Tableau.

## Objectives
- Explore EGFR inhibitor IC50 data.
- Perform data cleaning and exploratory data analysis.
- Calculate molecular descriptors using RDKit.
- Examine relationships between molecular properties and pIC50.
- Create an interactive Tableau dashboard.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- RDKit
- Tableau Public
- ChEMBL and PubChem

## Workflow
1. Retrieve EGFR inhibitor activity data.
2. Clean and organize IC50 measurements.
3. Calculate molecular descriptors.
4. Perform exploratory data analysis.
5. Visualize molecular properties and activity.
6. Build a Tableau dashboard.

## Important Note
This is an educational exploratory data-analysis project. Observed relationships do not establish drug efficacy or clinical suitability. Compound structures and activity records require identity and assay-level validation before drawing conclusions.
